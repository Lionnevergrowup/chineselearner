# 🦁 中文乐园

一个给 5–7 岁孩子的中文学习游戏：跟着小狮子乐乐学拼音、认汉字、写汉字、读词语和句子。
课程顺序参照 **统编版（2024）小学语文一年级上册**，共 32 课。手机、平板和电脑都能玩。

**▶ 开始玩：** https://lionnevergrowup.github.io/chineselearner/

开始页面：https://lionnevergrowup.github.io/chineselearner/#/start · 家长页面：https://lionnevergrowup.github.io/chineselearner/#/parents

*A Chinese learning game for young children (the companion of [Phonics Fun](https://lionnevergrowup.github.io/95percentgroup/)).
It follows the first-grade, first-semester Chinese textbook used in schools in China (统编版 2024, 32 lessons): pinyin (the
“phonics” of Chinese), character recognition, stroke-order writing, words and short sentences, with every instruction
spoken by 乐乐 the lion.*

## 课程

和 Phonics Fun 跟着一本 phonics 练习册走一样，中文乐园跟着全国小学一年级都在用的统编版语文一年级上册走：

| 单元 | 课 | 内容 |
|---|---|---|
| 第一单元 识字 | 1–4 | 天地人 · 金木水火土 · 口耳目手足 · 日月山川 |
| 第二单元 汉语拼音 | 5–8 | a o e · i u ü · b p m f · d t n l |
| 第三单元 汉语拼音 | 9–13 | g k h · j q x · z c s · zh ch sh r · y w |
| 第四单元 汉语拼音 | 14–18 | ai ei ui · ao ou iu · ie üe er · an en in un ün · ang eng ing ong |
| 第五单元 阅读 | 19–22 | 秋天 · 江南 · 雪地里的小画家 · 四季 |
| 第六单元 识字 | 23–26 | 对韵歌 · 日月明 · 小书包 · 升国旗 |
| 第七单元 阅读 | 27–29 | 小小的船 · 影子 · 两件宝 |
| 第八单元 阅读 | 30–32 | 比尾巴 · 乌鸦喝水 · 雨点儿 |

游戏里的练习和短句是为这个游戏编写的，不是课本原文；《咏鹅》《江南》、陶行知的《两件宝》和对韵、会意字儿歌（日月明，田力男……）是传统或公有领域的作品。

## 每课的小游戏

| 游戏 | 在哪些课 | 孩子做什么 |
|---|---|---|
| 🔤 认拼音 | 拼音课 | 点卡片听声母、韵母（“b，广播的播”），再戳破对的气球：听音找字母，或看图说出声母、韵母；后几题会出现长得像的字母（b d p q） |
| 👀 认汉字 | 识字、阅读课 | 点字卡听“天，天空的天”，再戳破对的气球：听音找字、看图找字、看拼音找字；后几题会出现长得像的字（人 入 八） |
| 🎵 四声 | 第 5 课起 | 口诀“一声平，二声扬，三声拐弯，四声降”，点四张声调卡听一听，再听音选声调（ā á ǎ à；识字课用本课的字） |
| ✏️ 描一描 | 拼音课 | 在四线三格里用手指描拼音字母；描得不够、描到外面或乱画都不算 |
| 🖌️ 写汉字 | 识字、阅读课 | 先看笔顺动画，再在田字格里一笔一笔写；笔顺或方向不对会提示，写错两次会提示下一笔 |
| 🧩 拼一拼 | 第 7–18 课 | 声母 + 韵母 → 音节（b + ā → bā，g + u + ā → guā），“前音轻短后音重，两音相连猛一碰”；再听音节，点出它的声母和韵母（后几题韵母的声调也要选对） |
| 📖 读一读 | 第 7–18 课 | 点音节卡，乐乐一部分一部分地拼读；再听音选音节、看图选音节、补全缺的声母或韵母；整体认读音节会特别说明 |
| 📖 读词语 | 识字、阅读课 | 点词语卡跟读；再听音选词、看图选词、补全缺的字、按顺序点出词语里的字；《日月明》还有“日 + 月 = 明” |
| 💬 读句子 | 每一课 | 跟乐乐一个词一个词地读句子，再把词语排好顺序，最后找出句子里缺的词 |
| 🎨 画一画 | 每一课 | 画一幅画，选一个本课的词当标签（可以拖动），还能保存图片 |

- 每题的类型会轮换，题目越来越难：前两题 3 个选项，后面 4 个，并且会出现长得像的字母、字或声调。
- 所有的汉字和词语上面都有拼音（家长页面可以隐藏拼音）。汉字用楷体显示，和课本、笔顺数据的字形一样。
- 乐乐会把每一句说明读出来，孩子不用认字也能玩。点左下角的乐乐可以再听一遍，也可以把乐乐拖到屏幕上任何地方。
- 背景音乐是一段五声音阶（do re mi sol la）的原创小曲，乐乐说话时会自动变小；首页底部“🎵 音乐”或家长页面可以关掉。
- 乐乐的声音是预先录好的（`audio/` 里 1500 多个 MP3），所以在任何浏览器里都能播放：微信里的浏览器、没有中文语音的安卓手机、打开了静音开关的 iPhone。
- 新题目出现的一瞬间不会算点击，所以手快的孩子不会因为上一题的点击被判错。
- 每完成一个游戏得一颗 ⭐，学完一课得一张动物贴纸 🏆（前 12 张是十二生肖）。
- **家长页面（👪）**：使用说明、语速、拼音显示/隐藏、音效、背景音乐、“显示乐乐说的话”（关掉声音也能玩）、“游戏长度：短”（每个游戏约 3 题）、把乐乐放回角落、声音测试、更新到最新版本、32 课的“家长 / 老师检查表”（会随着孩子完成游戏自动打勾，也可以手动勾选），以及“清除学习记录”（需要家长回答一道加法题）。
- 学习进度只保存在这台设备的这个浏览器里（localStorage），不会上传到任何地方。

## 小提示

- 请把音量调大。如果还是没有声音，请在手机自带的浏览器里打开（微信里点右上角“…”→“在浏览器打开”），并检查是否连接了蓝牙耳机或音箱。
- 每次玩 10–15 分钟就好。请孩子跟着乐乐大声读出来。
- 可以“添加到主屏幕”（分享 → 添加到主屏幕），以后像 App 一样打开。
- 首页、开始页面和家长页面底部会显示版本号（例如“版本 1 · 2026-10-02”）。网站有新版本时，首页会出现“🔄 新版本 … 来啦，点这里更新！”；也可以随时点首页右上角的 🔄。

## 用 GitHub Actions 发布到 GitHub Pages

这是一个静态网站：`index.html`、`favicon.ico`、`manifest.webmanifest`，加上 `audio/`、`fonts/`、`hanzi/`、`icons/`、`js/` 文件夹，不需要编译。

`.github/workflows/deploy.yml` 会在每次推送到 `main` 分支时，把这些文件打包并发布到 GitHub Pages。第一次使用前只需要设置一次：

1. 打开仓库的 **Settings** → **Pages**。
2. 在 **Build and deployment** 下，把 **Source** 选成 **GitHub Actions**。
3. 推送到 `main`（或在 **Actions** 页面手动运行 “Deploy to GitHub Pages”），大约一分钟后网站就会出现在 `https://lionnevergrowup.github.io/chineselearner/`。

在本地运行：在这个文件夹里执行 `python3 -m http.server`，然后打开 http://localhost:8000 。

每次提交前请运行 `python3 tools/stamp.py`：它会把版本号加一（每次提交一次），并记录语音文件的版本，这样浏览器不会把新页面和旧的语音文件混在一起。

## 修改课程内容或乐乐说的话

所有课程内容都在 `index.html` 的 `LESSONS` 里：每个字、词、句子都写着拼音（每个汉字一个音节），页面用它显示拼音，录音也按它来读，所以多音字（长、了、地）不会读错。
乐乐说的每一句话由 `allPhrases()` 列出（固定的话在 `T` 里，和课程有关的话在 `P` 里）。修改后请重新录音：

```sh
pip install onnxruntime numpy "misaki[zh]" lameenc praat-parselmouth
NODE_PATH=$(npm root -g) node tools/export_phrases.js      # 写出 tools/phrases.json（需要 playwright）
python3 tools/build_audio.py 模型文件夹                       # 只录新的句子，并更新 audio/manifest.js
```

模型文件来自 [Kokoro-82M-v1.1-zh-ONNX](https://huggingface.co/onnx-community/Kokoro-82M-v1.1-zh-ONNX)：把 `onnx/model.onnx`、`tokenizer.json` 和 `voices/` 下要用的声音（见 `build_audio.py` 里的 `VOICE`）放在同一个文件夹里。
`--redo "句子"` 可以重录某几句，`--all` 全部重录，`--show` 只显示每一句会怎么读（不录音）。没有录音的句子会用浏览器自带的中文语音朗读。

单个拼音音节（bā、ǚ、zhī）是这样录的：模型单独说一个音时，四个声调听起来几乎一样，所以先让模型说出这个音，再用 Praat（parselmouth）把它的音高改成标准的声调曲线（一声平、二声扬、三声拐弯、四声降），这样四个声调一定听得清清楚楚。

改了 `LESSONS` 里的字以后，还要运行：

```sh
python3 tools/build_hanzi.py 路径/hanzi-writer-data   # 要写的字的笔顺数据 → hanzi/（不给路径就从 jsdelivr 下载）
python3 tools/build_fonts.py 路径/gkai00mp.ttf         # 楷体字体只保留页面上用到的字 → fonts/kai.woff2
```

`gkai00mp.ttf`（AR PL KaitiM GB）在 Debian / Ubuntu 的 `fonts-arphic-gkai00mp` 软件包里。

检查：`python3 -m http.server 8765 &` 之后运行 `NODE_PATH=$(npm root -g) node tools/smoke_test.js`，它会打开每一课的每一个游戏，报告页面错误。

## 图标和背景音乐

图标是 `icons/icon.svg` 里红金色鬃毛的小狮子乐乐；`NODE_PATH=$(npm root -g) node tools/make_icons.js` 会画出其他尺寸（`favicon.ico`、iPhone 和安卓图标）。
背景音乐 `audio/music.mp3` 由 `python3 tools/make_music.py` 合成（筝一样的拨弦旋律、和弦、低音、木鱼和小鼓，约 40 秒），没有任何版权限制。
